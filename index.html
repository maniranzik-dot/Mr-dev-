📖 Unit 1: Sets

Meaning of a set

A set is a well-defined collection of objects called elements.

Example:
A = {1,2,3,4}

The numbers 1,2,3 and 4 are elements of set A.

Set notation

Sets are represented using curly brackets { }.

If an object belongs to a set we write:
x ∈ A

If an object does not belong to a set we write:
x ∉ A

Types of sets

  • Empty set: A set with no element. Example: { }
  • Finite set: A set with limited elements.
  • Infinite set: A set with unlimited elements.
  • Universal set: A set containing all objects under discussion.

Operations on sets

Union (A ∪ B): Elements found in A or B.

Intersection (A ∩ B): Elements common to both sets.

Difference (A - B): Elements in A but not in B.
