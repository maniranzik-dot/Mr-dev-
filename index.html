Unit 1: Indices and Surds

Meaning of Indices

An index (power) shows how many times a number is multiplied by itself.

Example:
2³ = 2 × 2 × 2 = 8

Laws of Indices

  • aᵐ × aⁿ = aᵐ⁺ⁿ
  • aᵐ ÷ aⁿ = aᵐ⁻ⁿ
  • (aᵐ)ⁿ = aᵐⁿ
  • a⁰ = 1
  • a⁻ⁿ = 1/aⁿ

Surds

A surd is an irrational root that cannot be simplified into a whole number.

Examples:
√2, √3, √5

Simplifying Surds

√12 = √(4×3) = 2√3

Unit 2: Polynomials

Meaning of Polynomial

A polynomial is an algebraic expression made up of variables, coefficients and powers.

Example:
3x² + 5x + 2

Operations on Polynomials

  • Addition
  • Subtraction
  • Multiplication
  • Factorisation

Factorisation

Example:
x² + 5x + 6
= (x+2)(x+3)

Unit 3: Simultaneous Linear Equations, Inequalities and Linear Programming

Simultaneous Equations

Two equations solved together to find common values of unknowns.

Methods of Solving

  • Substitution method
  • Elimination method
  • Graphical method

Example

x + y = 10
x - y = 2
Adding:
2x = 12
x = 6
y = 4

Inequalities

  • x > 5
  • x < 10
  • x ≥ 3
  • x ≤ 7

Linear Programming

Used to find maximum or minimum values using graphs and constraints.

Unit 4: Multipliers for Percentage Change

Percentage Increase

Multiplier = 1 + percentage increase

Example:
Increase 20%
Multiplier = 1.20

Percentage Decrease

Multiplier = 1 - percentage decrease

Example:
Decrease 15%
Multiplier = 0.85

Applications

  • Discounts
  • Profit and loss
  • Population growth
  • Depreciation
