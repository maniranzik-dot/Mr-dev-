Unit 9: Isometries

Meaning of Isometry

An isometry is a transformation that changes the position of a shape without changing its size or shape.

Types of Isometries

  • Reflection: A transformation where a shape is flipped over a line called a mirror line.
  • Rotation: A transformation where a shape turns around a fixed point.
  • Translation: A transformation where a shape moves from one position to another without turning.

Properties of Isometry

  • Length remains the same.
  • Angles remain the same.
  • Shape and size do not change.

Example

A triangle moved 5 units to the right is a translation.

Unit 10: General Data Statistics

Meaning of Statistics

Statistics is the process of collecting, organizing, presenting and interpreting data.

Types of Data

  • Primary data
  • Secondary data
  • Grouped data
  • Ungrouped data

Measures of Central Tendency

Mean:
Mean = Sum of values ÷ Number of values

Median:
The middle value when data is arranged in order.

Mode:
The value that appears most frequently.

Presentation of Data

  • Frequency tables
  • Bar charts
  • Histograms
  • Pie charts
  • Graphs

Unit 11: Probability

Meaning of Probability

Probability is the measure of the likelihood that an event will happen.

Formula

Probability =
Number of favourable outcomes ÷ Total number of possible outcomes

Probability Scale

  • Impossible event = 0
  • Possible event = between 0 and 1
  • Certain event = 1

Examples

A bag contains 5 red balls and 5 blue balls.

Probability of choosing a red ball:
= 5/10
= 1/2

  • Using tables
  • Using tree diagrams
  • Calculating probabilities of two events
