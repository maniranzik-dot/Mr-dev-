UNIT 9: CIRCLE THEOREMS

9.1 Angle at the Centre

The angle subtended by an arc at the centre of a circle is twice the angle subtended by the same arc at the circumference.

Angle at centre = 2 × angle at circumference
A / \ / \ / O \ / \ B---------C ∠BOC = 2∠BAC

9.2 Angle in a Semicircle

The angle formed in a semicircle is always a right angle.

Angle in a semicircle = 90°

9.3 Angles in the Same Segment

Angles subtended by the same chord in the same segment are equal.

∠ACB = ∠ADB

9.4 Cyclic Quadrilateral

Opposite angles of a cyclic quadrilateral are supplementary.

A + C = 180°
B + D = 180°
If one opposite angle is 115°:

Other angle = 180° − 115°

= 65°

UNIT 10: COLLINEAR POINTS AND ORTHOGONAL VECTORS

10.1 Collinear Points

Points are said to be collinear when they lie on the same straight line.

A •────────• B────────• C A, B and C are collinear.

10.2 Gradient Method

Three points are collinear if the gradient between the first and second points is equal to the gradient between the second and third points.

Gradient = (y₂ − y₁) / (x₂ − x₁)
Check whether A(1,2), B(3,6), C(5,10) are collinear.

Gradient AB: (6−2)/(3−1) = 4/2 = 2

Gradient BC: (10−6)/(5−3) = 4/2 = 2

Both gradients are equal.

Therefore A, B and C are collinear.

10.3 Vectors

A vector has both magnitude and direction.

AB = (x₂−x₁, y₂−y₁)

10.4 Orthogonal Vectors

Two vectors are orthogonal when they are perpendicular to each other.

a · b = 0

For: a = (a₁,a₂) and b = (b₁,b₂)

a · b = a₁b₁ + a₂b₂
Let: a = (2,3) b = (3,-2)

a · b = (2×3) + (3×−2)
= 6 − 6
= 0

Therefore the vectors are orthogonal.

(4×1) + (2×−2)

UNIT 11: ENLARGEMENT AND SIMILARITY 2D

11.1 Enlargement

Enlargement is a transformation that changes the size of a shape while keeping its shape the same.

Scale factor = Image length / Object length

11.2 Scale Factor

An original side is 4 cm and its image is 12 cm.

Scale factor = 12 / 4

= 3

11.3 Centre of Enlargement

The centre of enlargement is the fixed point from which the object and image are related.

A' / \ / \ / \ O-------A O = Centre of enlargement

11.4 Similar 2D Shapes

Similar shapes have:

  • Equal corresponding angles.
  • Proportional corresponding sides.
  • The same shape but not necessarily the same size.
Corresponding sides have a constant ratio.

11.5 Area Scale Factor

If the linear scale factor is k:

Area scale factor = k²
If scale factor = 3:

Area scale factor = 3²
= 9

UNIT 12: INVERSE AND COMPOSITE TRANSFORMATIONS

12.1 Inverse Transformation

An inverse transformation reverses a transformation and returns the image back to its original position.

T⁻¹(T(P)) = P

Examples include:

  • Inverse translation
  • Inverse rotation
  • Inverse reflection
  • Inverse enlargement

12.2 Inverse Translation

If a point is translated by (a,b), its inverse translation is (-a,-b).

(a,b) → (-a,-b)
Translation: (x,y) → (x+4,y+3)

Inverse: (x,y) → (x−4,y−3)

12.3 Composite Transformation

A composite transformation is when two or more transformations are performed one after another.

Object ↓ Transformation 1 ↓ Image 1 ↓ Transformation 2 ↓ Final Image

The order of transformations is important.

12.4 Example of Composite Transformation

First reflect a point in the x-axis, then translate it.

Reflection in x-axis: (x,y) → (x,-y)
Translation by (2,3): (x,y) → (x+2,y+3)
Starting point: P(1,2)

After reflection: P'(1,-2)

After translation by (2,3): P''(3,1)

Final image = (3,1)

UNIT 13: STATISTICS — BIVARIATE DATA

13.1 Bivariate Data

Bivariate data contains two variables for each observation.

Examples:

  • Height and weight
  • Study time and examination marks
  • Age and income

13.2 Scatter Diagram

A scatter diagram is used to display the relationship between two variables.

Y ↑ | • | • | • | • | • |________________→ X Positive correlation

13.3 Types of Correlation

  • Positive: both variables tend to increase.
  • Negative: one increases as the other decreases.
  • No correlation: no clear relationship.

13.4 Line of Best Fit

A line of best fit represents the general trend of a scatter diagram.

y = mx + c

13.5 Interpolation and Extrapolation

Interpolation estimates a value within the range of known data.

Extrapolation estimates a value outside the range of known data.

Exercise

If students who study longer generally obtain higher marks, what type of correlation is shown?

Positive correlation.
