UNIT 5: Quadratic Equations

5.1 Meaning of a Quadratic Equation

A quadratic equation is an equation of the form:

ax² + bx + c = 0,   a ≠ 0

Example:

x² + 5x + 6 = 0

Factorise:
x² + 5x + 6 = 0

(x + 2)(x + 3) = 0

Therefore:
x = -2 or x = -3.

5.2 Quadratic Formula

x = (-b ± √(b² - 4ac)) / 2a

For ax² + bx + c = 0.

Solve: x² - 5x + 6 = 0

a = 1, b = -5, c = 6

x = [5 ± √(25 - 24)] / 2
x = [5 ± 1] / 2

Therefore:
x = 3 or x = 2.

5.3 Discriminant

D = b² - 4ac

D > 0 → two real roots
D = 0 → equal roots
D < 0 → no real roots

Exercise

Solve: x² - 7x + 12 = 0

(x - 3)(x - 4) = 0

x = 3 or x = 4.

6.2 Gradient

m = (y₂ - y₁) / (x₂ - x₁)
Points: (2,3) and (4,7)

m = (7 - 3)/(4 - 2)
m = 4/2
m = 2.

UNIT 7: Compound Interest, Reverse Percentage and Proportional Change

7.1 Compound Interest

A = P(1 + r/100)ⁿ

P = Principal
r = interest rate
n = number of periods
A = final amount

Find the amount of 100,000 at 10% compound interest for 2 years.

A = 100000(1 + 10/100)²
A = 100000(1.1)²
A = 100000 × 1.21

A = 121,000

7.2 Reverse Percentage

Reverse percentage is used when the final value is known and the original value must be found.

Original = Final ÷ multiplier
A price after a 20% increase is 60,000.

Multiplier = 1.20
Original = 60,000 ÷ 1.20

Original = 50,000

7.3 Proportional Change

Direct proportion:

y ∝ x

Therefore:

y = kx

where k is the constant of proportionality.

UNIT 8: Right-Angled Triangles

8.1 Pythagoras' Theorem

a² + b² = c²

c is the hypotenuse — the longest side opposite the right angle.

/| / | c / | b / | /____| a 90°
If a = 3 cm and b = 4 cm:

c² = 3² + 4²
c² = 9 + 16
c² = 25

c = 5 cm

8.2 Trigonometric Ratios

sin θ = Opposite / Hypotenuse
cos θ = Adjacent / Hypotenuse
tan θ = Opposite / Adjacent

Remember: SOH CAH TOA

8.3 Finding an Angle

If opposite = 3 and hypotenuse = 5:

sin θ = 3/5
sin θ = 0.6

θ = sin⁻¹(0.6)
θ ≈ 36.9°

Exercise

A right-angled triangle has sides 6 cm and 8 cm. Find the hypotenuse.

c² = 6² + 8²
c² = 36 + 64
c² = 100
c = 10 cm
