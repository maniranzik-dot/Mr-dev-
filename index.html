Unit 1: Numbers

1.1 Types of Numbers

  • Natural numbers: Counting numbers (1,2,3,4...)
  • Whole numbers: Natural numbers including zero (0,1,2,3...)
  • Integers: Positive and negative whole numbers (...-3,-2,-1,0,1,2,3...)
  • Rational numbers: Numbers that can be written as a fraction.
  • Irrational numbers: Numbers that cannot be written as a simple fraction.

Operations on Numbers

Addition (+), Subtraction (-), Multiplication (×) and Division (÷)

Examples

5 + 3 = 8
10 - 4 = 6
6 × 5 = 30
20 ÷ 4 = 5

Unit 2: Set of Numbers

Meaning of Set

A set is a collection of well-defined objects called elements.

Examples

A = {1,2,3,4,5}
B = {a,b,c,d}

Types of Sets

  • Empty set
  • Finite set
  • Infinite set
  • Universal set

Set Operations

  • Union ( ∪ ) : Combining elements of two sets.
  • Intersection ( ∩ ) : Common elements between sets.

Unit 3: Linear Functions and Linear Inequalities

Linear Function

A linear function is a function that has a straight line graph.

General form:
y = mx + c

  • m = gradient/slope
  • c = y-intercept

Example

y = 2x + 3

Linear Inequality

An inequality compares values using:

  • > Greater than
  • < Less than
  • ≥ Greater than or equal to
  • ≤ Less than or equal to

Examples

x + 2 > 5
x > 3
